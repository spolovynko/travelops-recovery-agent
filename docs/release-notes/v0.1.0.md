# TravelOps Recovery Agent 0.1.0 — Phase 11 baseline

This first portfolio release completes the synthetic disruption workflow from
investigation through validated recommendation, exact human approval, fresh
revalidation, one idempotent transactional booking change, immutable audit, and
operator-visible evaluation.

Release evidence is frozen in dataset `phase-11.0.0` and the generated
machine-readable and Markdown reports under `reports/`. The deterministic suite
has no hosted-model dependency and treats zero unapproved or duplicate booking
writes as critical gates.

Security boundaries: all passenger, policy, disruption, model, and tool content
is untrusted; deterministic code owns permissions, business rules, proposal
eligibility, approval binding, revalidation, and execution. Traces redact
sensitive fields. The application uses synthetic data and a synthetic write
provider only.

This release is not production airline software. Demo actor headers are not
authentication; no real inventory is held or booking provider contacted; and
the small synthetic benchmark does not establish live-model or real-world
quality. See [Phase 11 notes](../notes/phase-11.md) for reproducibility and the
full limitation list.
